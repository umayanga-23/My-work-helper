## 3. Engineering & Workflow Guidelines
1. **Inspect First**: NEVER start blindly modifying code. Always inspect relevant files, understand existing dependencies, and search before assuming.
2. **Protect Existing Features**: Working features must never be broken or casually rewritten. Keep changes scoped strictly to the requested feature.
3. **Change Isolation**: Only edit files directly related to the task. List planned file changes and reasons before multi-file edits.
4. **Honesty with Errors**: Never pretend something works. Report errors with: Problem, Cause, Impact, Fix, and Verification.
5. **Standard Antigravity Workflow**:
   - Understand → Analyze → Plan → Implement → Verify → Report.
